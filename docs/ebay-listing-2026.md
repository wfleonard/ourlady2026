## Notes before you publish

1. **Frame status** — the old listing was for the stretched 24" x 36" canvas. If this listing is actually one of the framed SKUs, adjust the Item Specifics `Framed: Yes` and mention the frame style ("Gold Frame" etc.) in title and body.
2. **Price** — the old eBay listing wasn't priced in the text I pulled. The site charges $214 for framed 24" x 36" and $114 for rolled. Stretched (like the old eBay copy described) would fall between.
3. **Photos** — eBay favors listings with 10+ photos. Include: front view, corner detail, back-of-canvas, certificate close-ups, packaging you'll ship in.
4. **Handling window** — the schema on primosmaternos.com states 5-10 business days handling. Keeping the eBay listing consistent avoids the "why did the site say faster" complaint later.
